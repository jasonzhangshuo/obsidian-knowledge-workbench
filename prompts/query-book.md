# 独立查询约束

调用前提供明确的书籍目录、知识页、原文页目录和问题；不提供预期答案。限定只读，不使用编译对话记忆代替保存的数据。

先按问题检索编译知识页。默认元数据检索对中文不稳定：提取关键词，候选为空时回退到本书知识页全文及原文检索；不能把零候选当成没有资料。禁止全 Vault 扫描或读取私人晨页。

涉及跨章关系时实际对照多章；重要结论回查对应原文。回答与原文引文分开，摘录逐字复制，页码使用 PDF 物理页。不存在的信息明确标缺失，不以常识或外部材料补写。

记录实际使用的知识页、源页、检索方式及原句。回答后用程序验证引文在所标页存在；失败时只重查相关原页并保留首轮结果。无法验证时标记疑点，不静默改成通过。

只读查询不改变既有知识正文。是否已通过 MCP 调用，必须以真实工具调用记录单独确认。

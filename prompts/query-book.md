# 独立查询约束

使用 obsidian_knowledge MCP 查询指定书籍。验收时只给问题，以工具实际返回的内容为依据。

从问题提取 2–4 个有区分度的中文词组，使用 search_knowledge 查找候选，再用 read_knowledge 读取相关页。词组覆盖不足时服务会查本书原文。继续调整词组，或使用 search_source 查指定原句。区分检索未命中、资料不可用和证据不足。

涉及跨课关系时实际对照多课。重要结论用 read_source_page 回查对应原页与语境。区分整理归纳、讲记原文及模型推断。摘录连续逐字复制，注明书名、课次和 PDF 物理页。证据不足时说明本讲记的覆盖范围。

验收记录实际用到的知识页、源页、检索方式和原句。用 book_wiki_audit.py 核对引文在所标页是否连续出现。保留首轮失败和复查结果。

以客户端工具调用记录判定 MCP 闭环。由网页、直接读取文件或旧答案得到的结果不计入此次验收。

# 整书编译约束

调用前提供：书名、原文件哈希、书内分章清单及物理页映射、允许读取/写入的具体路径、当前阶段（预览或已授权正式保存）。不从本模板推断对任何其他目录的授权。

1. 使用当前项目可发现的 `llm-wiki` / `wiki-ingest`，固定指定 Vault 与书籍范围，不回退到其他全局库。
2. 每章完整读取后立即保存知识页和进度；工具返回被截断时补齐缺失部分，不能以标题、首尾或关键词扫描替代全文读取。
3. 保留作者原文、用户判断与 AI 归纳的区别。原文摘录必须连续、逐字不改，并标物理页；不得拼接、删掉数字或把反方设问当作者结论。
4. 每书使用独立目录；章节、概念和总览均保留出处、摘要、关系链接和审校状态，保持 `draft` 直到实际审校完成。
5. 完成全部章节后，基于原目录建立全书总览和真正跨章的概念页，再检查覆盖、链接和引用。
6. 用户明确要求只预览时遵守当次边界；当前书籍分析工作流的正式成果默认保存到 Obsidian，不能只存在 Codex 对话目录。
7. 不联网、不读取私人晨页、不改原书；调用外部模型处理资料需遵守用户选定方式与现有授权。
8. 最终说明实际完成/未完成范围、校验失败与修正、保存位置。提取成功和引用匹配均不等于语义无遗漏。
